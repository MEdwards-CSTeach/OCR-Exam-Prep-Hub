The steps to a higher grade

Each grade builds on the one before. The skills from lower steps still matter at the top.

D → C

Know it precisely. Key terms, secure methods, no blanks.

C → B

Explain and apply. Reasons for every point, using the scenario.

B → A

Evaluate and connect. Weigh options, conclude, link topics.

A → A*

Go beyond. Wider reading, depth and consistency.
