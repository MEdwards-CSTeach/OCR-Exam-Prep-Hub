Revision technique

Mnemonics and acronyms

A memorable word or phrase where each letter starts an item you need to remember.

At a glance

  • Time: 5–10 minutes each
  • Best for: Lists and orders you must recall exactly
  • You need: Imagination!

Why it works

A memorable phrase gives your brain a hook to hang a list on. It is great when you must recall a list in full or in the right order, such as the four ACID properties or the steps of the fetch cycle. Funny or strange phrases are the easiest to remember.

How to do it

  1. Write the list you need to learn, in order if order matters.
  2. Take the first letter of each item.
  3. Make a word or a silly sentence from those letters.
  4. Learn what each letter means, not just the phrase – the exam marks the meaning.
  5. Test yourself: write the phrase, then expand every letter.

Best topics for this technique

  • 1.1.1 Registers and the FDE cycle
  • 1.2.2 Stages of compilation
  • 1.3.2 ACID
  • 1.3.3 TCP/IP stack layers
  • 1.5.1 Computing legislation

These topics suit this technique well, but you can use it for any topic.

Tip: Mnemonics help you recall a list – they don’t help you understand it. Use them alongside another technique, like flashcards or teaching it.

Examples

Example 1

ACID – reliable database transactions

1.3.2

Phrase: The acronym is already given to you – learn a hook for each letter: All or nothing · Correct rules · In private · Done for good.

LetterStands forWhat it means
AAtomicityAll or nothing: a transaction is either completed fully or not at all.
CConsistencyA transaction keeps the database valid – all rules (e.g. referential integrity) still hold.
IIsolationTransactions running at the same time don’t interfere; the result is as if they ran one after another.
DDurabilityOnce committed, changes are saved permanently, even if the power fails.
Example 2

The fetch stage: Please Make More Coffee

1.1.1

Phrase: Please Make More Coffee = PC → MAR → MDR → CIR

LetterStands forWhat it means
PPCThe Program Counter holds the address of the next instruction. It is copied to the MAR.
MMARThe Memory Address Register sends that address along the address bus.
MMDRThe instruction comes back along the data bus into the Memory Data Register.
CCIRThe instruction is copied into the Current Instruction Register to be decoded.

More to try:

  • Legislation in date order: Clever Computers Defend Rights = CDPA 1988, CMA 1990, DPA 1998, RIPA 2000 (1.5.1)
  • Compiler stages: Lazy Students Get Old = Lexical, Syntax, code Generation, Optimisation (1.2.2)
  • TCP/IP layers, top to bottom: All Tigers Is Lazy = Application, Transport, Internet, Link (1.3.3)
