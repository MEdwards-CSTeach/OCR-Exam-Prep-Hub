Revision technique

Concept maps

Boxes for ideas, with labelled arrows that say exactly how the ideas are linked.

At a glance

  • Time: 20–30 minutes
  • Best for: Linking topics, especially Paper 1 to Paper 2
  • You need: Paper, sticky notes or a whiteboard

Why it works

High-mark answers explain how and why things are connected. In a mind map you just draw a line. In a concept map you must write the link on the arrow, e.g. “cache → fewer slow trips to RAM → performance”. This builds the links that Paper 2 synoptic questions need.

How to do it

  1. List 6–10 key ideas from one or more topics. Write each in a box (sticky notes work well).
  2. Arrange them so related ideas are close together.
  3. Draw arrows between ideas that are connected.
  4. Label every arrow with a short phrase: “causes”, “is limited by”, “is used by”, “stores”.
  5. Read each link as a sentence. If it doesn’t make sense, fix it – that is a gap in your understanding.

Best topics for this technique

  • 1.1.1 Structure and function of the processor
  • 1.4.2 Data structures
  • 2.1.2 Thinking ahead (caching)
  • 2.2.2 Computational methods
  • 2.3.1 Algorithms

These topics suit this technique well, but you can use it for any topic.

Tip: Use the links between the papers diagram on the course content page as a starting point for your own concept maps.

Examples

Example 1

What affects CPU performance?

1.1.1 + 1.1.2

Each factor has two links: how it improves performance and what limits it. That gives you both sides of an “evaluate” answer.

Example 2

Data structures and the algorithms that use them

1.4.2 + 2.3.1

This map links a Paper 1 topic to a Paper 2 topic – exactly the kind of connection synoptic questions test.
