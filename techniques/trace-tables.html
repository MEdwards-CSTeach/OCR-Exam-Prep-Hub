Revision technique

Trace tables

Follow an algorithm line by line, writing down the value of every variable as it changes.

At a glance

  • Time: 10–20 minutes per algorithm
  • Best for: Paper 2 algorithms and code
  • You need: The algorithm, paper, pencil

Why it works

Paper 2 asks you to follow, complete and correct algorithms. Tracing builds this skill and shows you exactly how an algorithm works. It also helps you find errors in code, which just reading the code does not.

How to do it

  1. Make a column for every variable, plus one for output.
  2. Go through the code one line at a time. Don’t skip ahead.
  3. Write a new value only when it changes, on a new row.
  4. Check conditions carefully (< or <=?) and count loops exactly.
  5. Check the final result makes sense, e.g. is the list really sorted?

Best topics for this technique

  • 1.2.3 Writing and following algorithms
  • 1.2.4 Little Man Computer programs
  • 2.2.1 Iteration, recursion, parameters
  • 2.3.1 Searching, sorting, stacks, queues, traversals

These topics suit this technique well, but you can use it for any topic.

Tip: Once you can trace an algorithm, try to write it from memory in pseudocode, then trace your own version to test it.

Examples

Example 1

Bubble sort on 5, 3, 8, 1

2.3.1
procedure bubbleSort(items)
    swapped = true
    while swapped == true
        swapped = false
        for i = 0 to items.length - 2
            if items[i] > items[i+1] then
                temp = items[i]
                items[i] = items[i+1]
                items[i+1] = temp
                swapped = true
            endif
        next i
    endwhile
endprocedure

Example 2

Your turn: binary search

2.3.1

Trace the algorithm to find 23 in this list. Indexes start at 0. Then press Check my answers.

list = [3, 8, 12, 17, 23, 31, 40]

function binarySearch(list, target)
    low = 0
    high = list.length - 1
    while low <= high
        mid = (low + high) DIV 2
        if list[mid] == target then
            return mid
        elseif list[mid] < target then
            low = mid + 1
        else
            high = mid - 1
        endif
    endwhile
    return -1
endfunction
lowhighmidlist[mid]

Hint

DIV is integer division, so (0 + 6) DIV 2 = 3. Compare list[3] with 23: is it smaller or bigger? That tells you whether low or high changes.
