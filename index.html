How to use this site

  1. Check the course content. Rate each topic red, amber or green so you know where to start.
  2. Read the topic notes. They are short. Follow the links when you need more detail.
  3. Make a revision tool. Each topic suggests the techniques that work best for it.
  4. Try the questions. Some are marked for you. For others, use the mark scheme to mark your own answer and improve it.
  5. Aim for the next grade. Read the exam tips and the page for your next step up.
