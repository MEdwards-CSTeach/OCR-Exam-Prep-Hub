Trees and binary search trees

A hierarchy with no cycles. BSTs keep data in order for fast search.

Key terms

  • Root, parent, child, leaf
  • Edge, subtree, height
  • Binary tree, BST
  • Pre-, in-, post-order
  • Breadth-first
  • In-order successor
  • Revision notes
  • Links and slides

What is a tree?

  • A connected graph with no cycles. A rooted tree has one root; every other node has exactly one parent.
  • Leaf: a node with no children. Subtree: a node and everything below it.
  • Height: edges on the longest root-to-leaf path (say whether you count edges or levels).
  • n nodes → n − 1 edges. Only one route from the root to any node.
  • A binary tree: each node has at most two children (left and right).

Binary search trees (BST)

  • A binary tree kept in order: left subtree smaller, right subtree larger – at every node.
  • Add: start at the root; go left if smaller, right if larger; add as a new leaf at the first empty space.
  • Search: compare, go left or right, repeat; stop when found or you reach a null pointer.
  • Balanced: O(log n). Data added in sorted order makes a chain: O(n).

Depth-first (pre, in, post-order) uses a stack or recursion. Breadth-first uses a queue. OCR often asks for depth-first (post-order).

Removing a node, and storing a tree in arrays

Three cases for removal

  1. Leaf: set the parent’s pointer to null.
  2. One child: point the parent at the child.
  3. Two children: replace with the in-order successor (go right once, then left as far as possible), then remove the successor.

Uses: file systems, the HTML DOM, abstract syntax trees in compilers (1.2.2), database indexes, decision trees, game AI.

Watch out for:

  • Saying a tree has “at most two children” – that is a binary tree.
  • Giving in-order when post-order is asked for. Read the question carefully.
  • Using a blank or 0 for a null pointer.
  • Saying a BST is “faster” with no reason – say half the remaining tree is discarded each step: O(log n).
  • Describing a traversal without using the nodes in the question (max 2 of 4 marks).

Quick quiz – marked for you

1. Give the in-order traversal of the BST above. AO2

Left, node, right. On a BST this always gives the values in sorted order: 20, 30, 40, 50, 60, 70, 80.

2. Give the depth-first (post-order) traversal of the BST above. AO2

Left, right, then node. 20, 40, then their parent 30; 60, 80, then 70; finally the root 50.

3. Give the breadth-first traversal of the BST above. AO2

Level by level, left to right: 50; then 30, 70; then 20, 40, 60, 80.

4. 45 is added to the BST above. Which node becomes its parent? AO2

45 < 50: go left. 45 > 30: go right. 45 > 40: go right – empty, so 45 becomes 40’s right child.

5. A node with two children is removed from a BST. What replaces it? AO1

The in-order successor (smallest value in the right subtree) is the next value in sorted order, so the BST rule still holds.

6. The values 10, 20, 30, 40, 50 are added to an empty BST in that order. What is the result? AO3

Each value is larger than the last, so each goes to the right: a chain. Searching becomes like a linked list: O(n).

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.2 exam tips for more help.

AO1[4 marks]

Give two similarities and two differences between a tree and a graph.

Mark your answer

Tick each mark point your answer includes.

Model answer: Both are made of nodes joined by edges, and both are non-linear structures. A tree has a root, whereas a graph does not. A graph can contain cycles, whereas a tree cannot.

How to improve a weak answer:

  • Write each difference as a pair: “a tree…, whereas a graph…”.
  • “A tree has at most two children” is wrong – that is a binary tree.
AO2[3 marks]

Describe how the BST above is searched for the value 45.

Mark your answer

Tick each mark point your answer includes.

Model answer: Compare 45 with the root, 50. It is smaller, so follow the left pointer to 30. 45 is larger than 30, so go right to 40. 45 is larger than 40, so go right, but 40’s right pointer is null, so the search stops: 45 is not in the tree.

How to improve a weak answer:

  • Use compare → direction → repeat, then say when you stop.
  • Use the actual nodes from the tree in every step.
AO3[9 marks]

Compare the use of a breadth-first traversal and a depth-first (post-order) traversal on the BST above. Include how each works and the order of the values returned.

Mark your answer

Tick each mark point your answer includes.

Model answer: Breadth-first starts at the root and visits every node on a level, left to right, before moving down, using a queue: 50, 30, 70, 20, 40, 60, 80. Depth-first (post-order) follows the left branch as far as it can, then the right, outputting a node only after both of its subtrees, using a stack and backtracking at each leaf: 20, 40, 30, 60, 80, 70, 50. Breadth-first reaches nodes near the root sooner, but its queue may hold a whole level, so it needs more memory in a wide tree. Depth-first stores only the current path, so it uses less memory and reaches the leaves sooner. If every node must be visited, depth-first is better here because it uses less memory; if the target is likely to be near the root, breadth-first would find it sooner.

How to improve a weak answer:

  • Structure it: know (how each works) → apply (write both orders) → evaluate → conclude.
  • Write out both orders in full – those are the application marks.
  • Without an evaluation and conclusion the answer is limited to the lower bands.

How to revise this

  • Trace tables – trace traversals, especially the BFS queue
  • Worked examples – add, search and remove step by step
  • Planning extended answers – the 9-mark traversal comparison

These are the best fit for this part of the topic, but you can use any revision technique that works for you.
