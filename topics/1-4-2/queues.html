Queues

First in, first out. Enqueue at the rear, dequeue at the front.

What is a queue?

  • FIFO: first in, first out. Items leave in the order they joined.
  • Enqueue adds at the rear. Dequeue removes from the front.
  • Two pointers: front and rear. A count of items is often kept too.

Operations (circular queue)

OperationStepsPseudocode
enqueue(item)Check not full. Move rear on by one, wrapping round. Store the item. Add 1 to count.if count == size then error
rear = (rear + 1) MOD size
queue[rear] = item
count = count + 1
dequeue()Check not empty. Read the item at front. Move front on, wrapping round. Subtract 1 from count.if count == 0 then error
item = queue[front]
front = (front + 1) MOD size
count = count − 1
isEmpty()True when count = 0.return count == 0
isFull()True when count = size.return count == size

Linear, circular and priority queues

Linear

Front moves along as items leave. Cells behind it are wasted, so the queue can say “full” when it isn’t.

Circular

Treats the array as a ring. (pointer + 1) MOD size wraps back to 0 so freed cells are reused. Use a count to tell full from empty.

Priority

Items with higher priority are dequeued first. Equal priority: FIFO. Used in A&E triage, scheduling and Dijkstra’s.

Uses: print jobs, keyboard buffers, packets waiting at a router, process scheduling, breadth-first search. Quick test: “in the order they arrived” = queue.

Watch out for:

  • Enqueueing at the front or dequeuing from the rear.
  • Forgetting the MOD so the pointer runs off the end of the array.
  • Not explaining how full and empty are told apart in a circular queue.
  • Calling a priority queue “not a queue” – it is still FIFO within a priority.

Quick quiz – marked for you

1. A circular queue has 6 cells (0–5). rear is 5. After one enqueue, what is rear? AO2

rear = (5 + 1) MOD 6 = 0. The pointer wraps back to the start to reuse the freed cell.

2. What is the main problem with a linear queue? AO1

As front moves along, the cells behind it can’t be reused. The queue can report full while cells are empty. A circular queue fixes this.

3. Queue(4) starts with front = 0, rear = −1, count = 0. Run enqueue(5), enqueue(2), dequeue(). What is front? AO2

Both enqueues move rear to 0 then 1. dequeue() returns 5 and moves front from 0 to 1. count is now 1.

4. In a circular queue, front and rear can be in the same place when it is full or empty. How is this usually solved? AO2

count == 0 means empty; count == size means full. (Another method is to always leave one cell empty.)

5. In a priority queue, two items have the same priority. Which is dequeued first? AO1

Within the same priority, a priority queue is still FIFO: the one that arrived first leaves first.

AO1[2 marks]

State what is meant by enqueue and dequeue.

Mark your answer

Tick each mark point your answer includes.

Model answer: Enqueue adds an item to the rear of the queue. Dequeue removes the item at the front of the queue and returns it.

How to improve a weak answer:

  • Say where each operation happens – front or rear.
AO2[3 marks]

Explain why a circular queue makes better use of memory than a linear queue.

Mark your answer

Tick each mark point your answer includes.

Model answer: In a linear queue, the front pointer moves along each time an item is dequeued, and the cells behind it can never be used again, so the queue can report that it is full while empty cells remain. A circular queue uses rear = (rear + 1) MOD size, so when the pointer reaches the end it wraps round to the start and reuses the freed cells.

How to improve a weak answer:

  • Explain the problem first, then how the circular queue solves it.
  • Mention MOD and wrapping round – that is the key idea.
AO2[4 marks]

A circular queue uses the array queue of size size, with pointers front and rear and a variable count. Write pseudocode for enqueue(item).

Mark your answer

Tick each mark point your answer includes.

Model answer: procedure enqueue(item)
  if count == size then
    print("Queue full")
  else
    rear = (rear + 1) MOD size
    queue[rear] = item
    count = count + 1
  endif
endprocedure

How to improve a weak answer:

  • Check for full before adding.
  • Move rear before storing the item.
  • Don’t forget to update count.
