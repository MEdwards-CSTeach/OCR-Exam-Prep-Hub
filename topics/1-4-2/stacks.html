Stacks

Last in, first out. Push and pop at the top.

What is a stack?

  • LIFO: last in, first out. The last item added is the first removed.
  • Everything happens at one end: the top. One pointer is needed.
  • Often built on a fixed-size array. top = −1 means the stack is empty.

Operations

item = stack[top]

Overflow, underflow and the call stack

Overflow and underflow

  • Stack overflow = push onto a full stack. Prevented by checking isFull.
  • Stack underflow = pop from an empty stack. Prevented by checking isEmpty.

The call stack

  • Calling a subroutine pushes a stack frame: return address, parameters, local variables.
  • Returning pops the frame and jumps to the return address.
  • This is what makes recursion work. No base case = stack overflow.

Uses: undo, browser back button, the call stack, checking balanced brackets, depth-first search. Quick test: “most recent first” = stack.

Watch out for:

  • Mixing up overflow (push when full) and underflow (pop when empty).
  • Forgetting the check before push or pop in pseudocode.
  • Updating top in the wrong order: push moves top then stores; pop reads then moves top.
  • Saying pop deletes the data – it just moves the pointer; the old value is overwritten later.

Quick quiz – marked for you

1. A stack of size 3 starts empty (top = −1). Run: push(4), push(7), pop(), push(2). What is the value of top? AO2

push(4) → top 0, push(7) → top 1, pop() → top 0, push(2) → top 1. The stack holds 4, 2 with 2 on top.

2. Stack overflow happens when… AO1

Overflow = push when full. Underflow = pop when empty. Both are prevented by checking isFull / isEmpty first.

3. Which of these is best modelled by a stack? AO2

Undo reverses the most recent action first: last in, first out. The others are served in arrival order, so they are queues.

4. Function A calls B, and B calls C. Which stack frame is on top of the call stack while C runs? AO2

The most recent call is always on top. C’s frame is popped first when it returns, then B’s, then A’s.

5. Why can a recursive function with no base case crash? AO3

Without a base case the calls never return, so frames keep being pushed until the call stack runs out of memory: stack overflow.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.2 exam tips for more help.

AO1[2 marks]

Explain what is meant by LIFO, using an example.

Mark your answer

Tick each mark point your answer includes.

Model answer: LIFO means last in, first out: the most recently added item is the first to be removed. For example, in an undo feature the last action carried out is the first one undone.

How to improve a weak answer:

  • Don’t just expand the acronym – explain what it means.
  • Make the example show the LIFO behaviour, not just name a use.
AO2[4 marks]

A stack is stored in the array stack with a pointer top, which is −1 when empty. Write pseudocode for a function pop() that returns the top item, or reports an error if the stack is empty.

Mark your answer

Tick each mark point your answer includes.

Model answer: function pop()
  if top == -1 then
    print("Stack empty")
    return null
  else
    item = stack[top]
    top = top - 1
    return item
  endif
endfunction

How to improve a weak answer:

  • Always check for underflow first.
  • Read the item before moving top, or you return the wrong item.
  • Make sure the item is returned – it is easy to forget.
AO3[3 marks]

Explain how a stack is used when subroutines are called and return.

Mark your answer

Tick each mark point your answer includes.

Model answer: Each time a subroutine is called, a stack frame holding its return address, parameters and local variables is pushed onto the call stack. When the subroutine finishes, its frame is popped and the program jumps to the return address. Because the stack is LIFO, the most recently called subroutine always returns first, so nested calls return in the right order.

How to improve a weak answer:

  • Name what is in a stack frame.
  • Explain why LIFO is needed, not just that a stack is used.
