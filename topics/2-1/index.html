2.1 Elements of computational thinking

Five ways of thinking that help you solve problems before you write any code. Every 2.1 question in the exam is set in a scenario – practise applying each idea to it.

Five ways of thinking

  • Abstractly: take detail away
  • Ahead: plan inputs, outputs, reuse
  • Procedurally: break it down
  • Logically: find the decisions
  • Concurrently: what can run at once?
