2.1 exam tips: computational thinking

What examiners look for in abstraction, thinking ahead, decomposition, decisions and concurrency questions – with weak and good answers.

The golden rule

Every 2.1 question is set in a scenario. Generic answers score little. Name things from the question in every point.

What the examiner looks for

TopicEarns marksLoses marks
2.1.1 AbstractionTwo-part definition: remove detail + to focus on what matters. A named detail and a reason for each.“It makes it simpler.” Mixing it up with decomposition.
2.1.2 Thinking aheadInputs and outputs named from the scenario. Caching: what is stored and why.Processes listed as inputs. “It uses the cache.”
2.1.3 ProcedurallyBox names from the scenario, one task per box. Sub-procedure with name, parameters and return.A flowchart instead of a structure diagram. Boxes called “Process”.
2.1.4 LogicallyCondition + linked outcome. The False path: “if neither is true, return false” (2022).“It checks the input.” Naming the construct, not the condition.
2.1.5 ConcurrentlyOne starts before another finishes; time slices; locking; x processors is not 1/x of the time.“Two things at once.” Only benefits in a “discuss”. No recommendation when asked.

Command words

  • Identify / State: name it. One mark each, no explanation.
  • Describe: say what it is or what happens.
  • Explain: a point, then why – in the scenario.
  • Discuss / Evaluate: both sides, then a judgement.

Answering a decision question

  1. Check: the condition, as a yes/no question.
  2. If True: exactly what happens.
  3. If False: what happens instead.

Weak and good answers

Question: A council is simulating traffic at a new roundabout. Identify two details that could be removed and explain why. [4]

Weak answer 1 mark

Colours and the weather, because they are not needed.

Good answer 4 marks

The colour of each car can be removed: it does not change how fast a car gets round. Drivers’ names can be removed: they have no effect on traffic flow.

How to turn the weak answer into a good one:

  • Weather may matter to traffic – only remove details that don’t change the answer.
  • Give a reason for each detail, linked to traffic flow.

Question: An aeroplane simulator is being designed. Describe how caching can be used in the simulator. [2]

Weak answer 0 marks

Caching makes the simulator faster because it uses the cache.

Good answer 2 marks

Data that has been used, such as the design of the clouds, is stored in the cache so it can be accessed quickly if it is needed again.

How to turn the weak answer into a good one:

  • Don’t repeat the question. Say what is stored, named from the scenario.
  • Then say why: faster access if needed again.

Question: A gym booking program. Identify two inputs for the program. [2]

Weak answer 0 marks

The data the member enters and their choice.

Good answer 2 marks

Membership ID. Date of the class.

How to turn the weak answer into a good one:

  • Name specific data from the scenario.
  • Short and specific scores – no explanation needed for “identify”.

Question: Mabel is writing a game. Explain how decomposition can aid the design of this program. [2]

Weak answer 0 marks

It makes the program easier.

Good answer 2 marks

She can split the game into sub-problems such as levels, enemies and lives. Each is simpler to solve and can be tackled independently.

How to turn the weak answer into a good one:

  • Say what decomposition does (split into sub-problems).
  • Then why it helps here – easier how?

Question: Board game: describe two logical conditions and how the result will affect the outcome of the game. [4] (June 2024)

Weak answer 1 mark

Condition: check the dice. Outcome: they move. Condition: if they win. Outcome: game over.

Good answer 4 marks

Has the player landed on square 100? If so, they are announced as the winner. Has the timer reached 0? If so, the game is a draw.

How to turn the weak answer into a good one:

  • “Check the dice” is not a True/False question – write the condition as a question.
  • “If they win” is too vague: what makes them win?

Question: Online circus game. Explain why concurrent processing is needed to allow multiple users to log in at the same time. [3] (Oct 2021)

Weak answer 1 mark

So lots of people can play at the same time and it is faster.

Good answer 3 marks

Many users will send requests to the server at once, and each needs a reply in a reasonable time. The server can deal with other requests while one waits, so one user doesn’t slow down the rest.

How to turn the weak answer into a good one:

  • Don’t repeat the question back.
  • “Faster” than what? Explain the effect on the users.

Structuring a 9-mark “discuss” answer

  1. Define (AO1): what the technique is and how it works – e.g. time slices or several processors.
  2. Apply (AO2): which parts of this system use it, and why.
  3. Weigh up (AO3): benefits and drawbacks, each linked to the scenario.
  4. Conclude (AO3): is it worth it here? Give a reason.

Marks: about AO1 4, AO2 2, AO3 3. The top band (7–9) needs a clear line of reasoning, in context.

Model extract – ticket website (Nov 2020): “Concurrent processing means several processes are in progress at the same time, with one starting before another has finished. Thousands of customers will log in and buy tickets at once, and each request can be handled by its own thread, so nobody waits in a queue. However, two threads could sell the same seat, so record locking is needed, which makes it harder to write and test. Overall it is essential: without it only one customer could buy at a time.”
