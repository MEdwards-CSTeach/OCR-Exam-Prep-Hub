Question

Mixed quiz

Mixed quiz – marked for you

1. A class is… AO1

The class is the template; objects are instances of it.

2. Score can only be changed by addPoints(), which checks the value. Which pillar? AO2

Private data, changed only through a validating method.

3. SavingsAccount reuses all of BankAccount’s code. Which pillar? AO2

SavingsAccount is a subclass of BankAccount.

4. A Penguin overrides the move() method it inherits from Bird, so it swims. Which pillar? AO2

Overriding: the same call, move(), behaves differently for a Penguin.

5. Playlist and Song: which relationship? AO2

A playlist has songs.

6. Why should constructor parameters have different names from the attributes? AO3

name = name is ambiguous; name = pName is clear. OCR mark schemes require different identifiers.
