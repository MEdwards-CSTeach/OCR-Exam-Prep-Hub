2.2.1 exam tips: OOP

What examiners look for in object-oriented programming questions, with weak and good answers.

Where it comes up

OOP is examined on both papers (1.2.4 on Paper 1, 2.2.1 on Paper 2): definitions, writing code, and one long discussion question.

How OOP has been examined

PaperScenarioWhat it askedMarks
Oct 2021 P1AttendanceState the meaning of object, method, attribute3
Nov 2020 P1SupermarketConstructor; encapsulation; inheritance for a new item type3–4
Oct 2021 P2City buildingsPurpose of a constructor; describe inheritance; write a subclass1–6
June 2019 P2Garden designDeclare a class and a subclass with private attributesup to 6
Nov 2020 P1GamesDiscuss OOP over procedural: inheritance, encapsulation, polymorphism12

What the mark schemes reward

Earns marks

  • Object “instantiated from a class”.
  • Inheritance naming both classes from the scenario.
  • Encapsulation: private + set method + the validation.
  • Code: inherits, super.new, every parameter used.

Loses marks

  • Parameters with the same names as attributes: “must use different identifier names” (Nov 2020).
  • Wrong case or spelling of a given identifier.
  • Definitions with no link to the scenario.
  • Mixing up class and object.

Define it, then apply it: name the classes from the question.

Weak and good answers

Question: The classes office and house inherit from building. Describe what is meant by inheritance with reference to these classes. [2] (Oct 2021)

Weak answer 1 mark

Inheritance is when a class gets things from another class.

Good answer 2 marks

The subclasses office and house take on the attributes and methods of the superclass building, such as numberFloors and getWidth().

How to turn the weak answer into a good one:

  • Which things? Say attributes and methods.
  • Which classes? Name the subclasses and the superclass from the question.

Question: Discounts above 50 kept being set. How could encapsulation stop this? [3] (Nov 2020)

Weak answer 0 marks

Use encapsulation to protect the data.

Good answer 3 marks

Make discount private. Add a public setDiscount method as the only way to change it. Inside it, only accept values from 0 to 50.

How to turn the weak answer into a good one:

  • Name the term isn’t enough – describe the three steps.
  • Use the attribute name from the question.

Question: Write the constructor for Member. Name and age are passed in; visits starts at 0. [4]

Weak answer 1 mark

public procedure new(name, age)
name = name
age = age
endprocedure

Good answer 4 marks

public procedure new(pName, pAge)
name = pName
age = pAge
visits = 0
endprocedure

How to turn the weak answer into a good one:

  • Parameters must have different names from the attributes.
  • Set every attribute – visits = 0 was missed.

Question: State the purpose of a constructor. [1] (Oct 2021)

Weak answer 0 marks

It constructs the class.

Good answer 1 mark

To create an instance of an object from a class, setting its starting values.

How to turn the weak answer into a good one:

  • A constructor makes an object, not a class.
  • Use the exam wording: “create an instance of an object from a class”.

Structuring the 12-mark discussion

  1. Know (AO1): define each pillar accurately, and classes, objects, attributes and methods.
  2. Apply (AO2): use the scenario – an Enemy class, many enemy objects each with its own speed and energy.
  3. Evaluate (AO3): reuse and security vs more planning; procedural is fine for small tasks.
  4. Conclude: a judgement that answers the question, for this context.

Each paragraph: point, example, so what. See the model paragraph on the modelling page and planning extended answers.
