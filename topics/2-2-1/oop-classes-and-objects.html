Two ways to organise a program

Procedural

A sequence of steps in procedures and functions. Data is kept separately and passed in.

health = 100
procedure takeHit(health, dmg)
    return health - dmg
endprocedure
health = takeHit(health, 10)

Object-oriented

A set of objects. Each holds its own data and the methods that act on it.

class Enemy
    private health
    public procedure takeHit(dmg)
        health = health - dmg
    endprocedure
endclass
orc.takeHit(10)

Built fromProcedures and functionsClasses and objects
DataSeparate from the code, often global or passed inInside each object, usually private
ReuseCall a subroutine againInherit from a class, make many objects

Procedural asks: what steps? OOP asks: what things, and what can each one do? The dot in object.method() is the giveaway.

Classes, objects, attributes and methods

TermMeaningExample
ClassA template or blueprint that defines the attributes and methods its objects will havePet
ObjectAn instance of a class, with its own value for each attributerex, luna
AttributeA variable belonging to an object that holds its data (its state)name, hunger
MethodA procedure or function in a class: an action the object can performfeed()
ConstructorThe method new that runs when an object is created and sets its starting valuesnew(givenName)
InstantiationMaking an object from a classrex = new Pet("Rex")

Quick test: a noun or adjective is probably an attribute; a verb is probably a method.

Writing a class

OCR pseudocode

class Pet
    private name
    private hunger
    public procedure new(givenName)
        name = givenName
        hunger = 50
    endprocedure
    public procedure feed()
        hunger = hunger - 20
    endprocedure
endclass

rex = new Pet("Rex")
rex.feed()

Python

class Pet:
    def __init__(self, givenName):
        self.__name = givenName
        self.__hunger = 50

    def feed(self):
        self.__hunger = self.__hunger - 20

rex = Pet("Rex")
rex.feed()

Exam wording: the constructor creates an instance of an object from a class. In the exam, pseudocode or Python are both fine.

Watch out for:

  • Mixing up class (the template) and object (one instance).
  • Constructor parameters with the same names as the attributes – the mark scheme wants different identifiers (Nov 2020).
  • Calling an attribute a method, or the other way round.
  • Definitions with no link to the scenario in the question.

Quick quiz – marked for you

1. An object is… AO1

The class is the template; an object is one instance made from it, with its own attribute values.

2. In car.drive(30), what is drive? AO1

drive is a method called on the object car. 30 is the parameter.

3. What does a constructor do? AO1

The constructor (new in OCR pseudocode, __init__ in Python) creates an instance of an object from a class.

4. player.jump() is an example of… AO2

A method called on an object – the dot is the giveaway.

5. Pet sets hunger = 50 in its constructor, and feed() takes 20 off. After rex = new Pet("Rex"), rex.feed(), rex.feed(), what is rex’s hunger? AO2

50 − 20 − 20 = 10. Each object keeps its own hunger.

6. Which is best written procedurally? AO3

A short task with clear steps doesn’t need classes. OOP suits large systems of interacting things.

Exam-style questions – mark them yourself

AO1[2 marks]

A gym app uses OOP. State what is meant by a class and an object.

Mark your answer

Tick each mark point your answer includes.

Model answer: A class is a template that defines the attributes and methods its objects will have, such as Member. An object is an instance of a class with its own values, such as one particular gym member.

How to improve a weak answer:

  • Use “template” and “instance” – the exam keywords.
  • Link to the scenario: Member and a particular member.
AO2[4 marks]

Each Member has a name, an age and a number of visits. All attributes are private. Write the constructor for Member. Name and age are passed in; visits starts at 0.

Mark your answer

Tick each mark point your answer includes.

Model answer: public procedure new(pName, pAge)
  name = pName
  age = pAge
  visits = 0
endprocedure

How to improve a weak answer:

  • Use different names for parameters and attributes (pName, not name).
  • Don’t forget the attribute that has a fixed start value (visits = 0).
AO1[3 marks]

State the meaning of the terms object, method and attribute.

Mark your answer

Tick each mark point your answer includes.

Model answer: An object is an instance of a class. A method is a procedure or function in a class – an action the object can perform. An attribute is a variable belonging to an object that stores its data.

How to improve a weak answer:

  • One clear sentence per term.
  • If the question has a scenario, add an example from it.
