Von Neumann, Harvard and contemporary architecture

How a processor gets its instructions and data, and why one shared bus can slow everything down.

The stored program concept

  • Programs are held in main memory alongside the data, and loaded to be run.
  • Instructions are fetched, decoded and executed one at a time; the order only changes with a jump.
  • Before this (ENIAC, 1945) a new job meant rewiring. The Manchester Baby (1948) was the first to run a program held in its own memory.

Von Neumann and Harvard

Von NeumannHarvard
MemoryOne memory for instructions and dataSeparate memories for instructions and data
BusesOne shared busSeparate buses for each memory
FetchingOne fetch at a time: the von Neumann bottleneckInstruction and data fetched at the same time
CostSimpler, cheaper control unitMore buses, more pins, more cost
FlexibilityFree memory can hold code or dataMemories can have different sizes and word lengths
Used inPCs, laptops, servers (general purpose)Embedded systems and DSP: microwaves, watches

Contemporary architecture

  • Modern CPUs combine both ideas – often called modified Harvard.
  • One main memory holds instructions and data (von Neumann).
  • Inside the CPU, the L1 cache is split into an instruction cache and a data cache (Harvard).

Watch out for:

  • Saying Harvard has “two processors” – it has two memories and two buses.
  • Describing von Neumann without saying the one memory holds both data and instructions.
  • Forgetting the bottleneck is caused by the single shared bus.
  • A 9-mark answer with no justified conclusion in context.

Quick quiz – marked for you

1. What is the stored program concept? AO1

Instructions and data are both just binary held in main memory, so a new job only needs a new program loading.

2. What causes the von Neumann bottleneck? AO2

The processor has to wait while one bus carries both instructions and data, one item at a time.

3. A microwave oven’s controller runs one fixed program for life and must react instantly. Which architecture? AO2

An embedded system where speed matters more than flexibility: Harvard fetches instruction and data together.

4. A laptop switches between a browser, a game and a word processor all day. Which architecture? AO2

General purpose: programs of any size load into one main memory. (A modern laptop CPU is contemporary inside, but its memory model is von Neumann.)

5. A desktop CPU has one RAM but separate L1 instruction and data caches. Which architecture? AO2

Von Neumann main memory plus a Harvard-style split cache: contemporary (modified Harvard).

6. A program is too big for its instruction memory, but the data memory is half empty. Which architecture could use the free space? AO3

Only a shared memory lets free space hold either code or data.

AO1[2 marks]

Describe what is meant by the term ‘Von Neumann architecture’. (October 2021)

Mark your answer

Tick each mark point your answer includes.

Model answer: In von Neumann architecture, data and instructions are stored together in the same main memory, and they are transferred to the processor along one shared bus.

How to improve a weak answer:

  • Say what the one memory holds: both data and instructions.
  • Mention the single shared bus for the second mark.
AO1[1 mark]

Give one way that the Harvard architecture differs from the Von Neumann architecture. (October 2021)

Mark your answer

Tick each mark point your answer includes.

Model answer: Harvard architecture stores instructions and data in separate memories, with separate buses.

How to improve a weak answer:

  • For a 1-mark difference, describe Harvard clearly – the comparison with von Neumann is implied.
AO3[9 marks]

Discuss the difference between Von Neumann and Harvard architecture. Refer to how each stores instructions and data, and the benefits of each. (June 2024 style)

Mark your answer

Tick each mark point your answer includes.

Model answer: Von Neumann stores instructions and data in one main memory and moves them along one shared bus, whereas Harvard keeps them in separate memories with separate buses. Because Harvard has two buses, it can fetch an instruction and its data at the same time, while von Neumann must fetch them one after another, creating a bottleneck. However, von Neumann is simpler and cheaper, and its single memory can be shared between large programs or large amounts of data. Harvard’s memories can be different sizes and word lengths, which suits embedded systems such as a microwave controller or a DSP chip, where a fixed program must run quickly. A general-purpose games PC benefits from von Neumann’s flexibility. In practice modern CPUs use both: one RAM, with a split L1 cache.

How to improve a weak answer:

  • Plan with know → apply → weigh up → conclude.
  • Use examples of devices for the application marks.
  • 7–9 marks needs a justified conclusion, e.g. comparing a games PC and a microwave.
