Instruction sets: CISC and RISC

  • An instruction set is every machine code instruction a processor can carry out (opcode + operand).
  • Each family has its own set (x86, ARM). Code compiled for one will not run on another.
CISC – ComplexRISC – Reduced
InstructionsMany, complexFewer, simpler
Cycles per instructionOften severalOne
Program lengthShorter: less RAMLonger: more RAM
CircuitsComplex, more transistorsSimpler, fewer transistors
Power and heatMoreLess
PipeliningHarderEasier
CompilerSimplerMore complex
Typical useMost PCs and serversPhones, tablets, watches

Instruction Race result: (A + B) × C took CISC 4 lines and 13 cycles, and RISC 8 lines but only 8 cycles. Same answer: 32.

GPUs

  • A co-processor with thousands of simple cores.
  • Carries out the same instruction on lots of data at once: SIMD.
  • Built for pixels, but used for: training AI, weather and science models, video encoding, financial risk, crypto mining, password cracking.
  • Exam tip: link the use to “the same calculation on lots of data”.

Multicore and parallel systems

Parallel helps when…

  • The task splits into independent parts (frames, pixels)
  • Several programs run at once
  • A server handles many users

Parallel doesn’t help when…

  • Each step needs the one before (a running total)
  • Cores wait for shared memory
  • Splitting and combining takes time
  • The software only uses one core

A multicore CPU is MIMD: many instructions on many data. Doubling the cores does not double the speed.

Watch out for:

  • Saying RISC is “slower” – each instruction takes one cycle; programs are longer but often faster.
  • Giving a graphical use when asked for a non-graphical GPU use.
  • “It is faster” on its own for a GPU use – say why: the same calculation on lots of data.
  • Saying more cores always means proportionally faster.

Quick quiz – marked for you

1. Which type of processor is most likely in a smartphone, and why? AO2

Phones run on batteries with no fan, so RISC’s simpler circuits, lower power and lower heat suit them.

2. Which statement describes RISC? AO1

RISC uses a small set of simple instructions, each taking one cycle, which makes pipelining easier.

3. Which is a non-graphical use of a GPU? AO2

Training AI repeats the same matrix calculations on huge amounts of data – ideal for thousands of cores (SIMD).

4. Each value in a running total needs the total before it. Will extra cores speed it up? AO3

Sequential tasks can’t be split into independent parts, so extra cores sit idle.

5. What does SIMD stand for? AO1

Single Instruction, Multiple Data: one instruction carried out on many pieces of data at once – how a GPU works.

6. Compared with RISC, CISC programs… AO1

One complex CISC instruction does the work of several RISC ones, so programs are shorter.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.1 exam tips for more help.

AO1[2 marks]

Describe one difference between a CISC and a RISC processor.

Mark your answer

Tick each mark point your answer includes.

Model answer: A CISC processor has a large set of complex instructions, whereas a RISC processor has a small set of simple instructions.

How to improve a weak answer:

  • Marked in pairs: say what each type does for the same feature.
  • Other pairs: several cycles / one cycle; harder / easier to pipeline; less / more RAM.
AO2[3 marks]

Describe how parallel processing would speed up a computer used for video rendering.

Mark your answer

Tick each mark point your answer includes.

Model answer: With parallel processing, the rendering job is split into parts that run at the same time on different cores. Each core works on different frames of the video, so the whole video is rendered in less time than one core working through every frame in turn.

How to improve a weak answer:

  • Use the context: frames or sections of the video.
  • Say what is split and what happens at the same time.
AO2[2 marks]

Describe one non-graphical use an insurance company may have for a GPU.

Mark your answer

Tick each mark point your answer includes.

Model answer: The company could use a GPU to model risk, because this needs the same complex calculations carried out on data for millions of customers, which the GPU’s many cores can do at the same time.

How to improve a weak answer:

  • “It is faster” on its own gets no marks.
  • Any graphical use (such as displaying the website) is not credited.
  • Say what the GPU does and why it suits the company.
AO3[12 marks]

A charity’s desktops use CISC processors. Discuss whether its new mobile devices should use CISC or RISC processors. (June 2022 style)

Mark your answer

Tick each mark point your answer includes.

Model answer: Using CISC in the mobile devices would mean they could run exactly the same software as the charity’s desktops, whereas RISC devices would need software recompiled or emulated. However, RISC processors use less power, so staff working away from the office get longer battery life, and they produce less heat, so devices can be thin and light with no fan. RISC chips are also usually cheaper, which matters for a charity’s budget. CISC programs need less RAM, but this is less important than battery life on a mobile device. Overall the charity should choose RISC, because battery life, weight and cost matter most for mobile staff, and most common software is already available for RISC devices.

How to improve a weak answer:

  • Plan the differences first, then apply each one to mobile devices for a charity.
  • 9–12 marks need a justified conclusion for the charity.
  • Don’t forget the software compatibility issue – it is the main argument for CISC.

How to revise this

  • Comparison tables – CISC vs RISC; CPU vs GPU
  • Planning extended answers – the 12-mark CISC or RISC question
  • Teach it – explain SIMD and why parallel doesn’t always help

These are the best fit for this part of the topic, but you can use any revision technique that works for you.
