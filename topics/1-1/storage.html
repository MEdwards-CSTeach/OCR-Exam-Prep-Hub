Storage and memory

Magnetic, flash and optical storage, RAM and ROM, and virtual storage: choose the right one and justify it.

Primary and secondary storage

  • RAM holds programs and data in use now: very fast, but volatile (lost when the power goes off).
  • Secondary storage keeps files long term: non-volatile, much larger and cheaper per GB, but slower – programs are loaded into RAM to run.
  • Six ways to compare: capacity, cost (per GB), speed, portability, durability, reliability.
    Can Cats Swim Past Dogs Running?

Magnetic, flash and optical

Magnetic

Areas magnetised one way or the other; a read/write head over a spinning disk. HDD, tape.

  • ✓ Huge capacity, lowest cost per GB
  • ✗ Moving parts, slower, noisy
  • Uses: PCs, servers, backups; tape for archives

Flash (solid state)

Charge trapped in memory cells; no moving parts. SSD, USB, SD card.

  • ✓ Fastest, tough, light, low power
  • ✗ Higher cost per GB; limited writes
  • Uses: laptops, phones, cameras

Optical

A laser reads pits and lands. CD 700 MB, DVD 4.7 GB, Blu-ray 25–100 GB.

  • ✓ Very cheap to make and post
  • ✗ Low capacity, slowest, scratches
  • Uses: films and games for sale; archives

RAM and ROM

RAMROM
Stands forRandom access memoryRead only memory
Power offVolatile: contents lostNon-volatile: contents kept
Read / writeRead and writeRead only
StoresOS, programs and data in use nowFirmware (BIOS/UEFI): POST and bootstrap loader
SizeLarge: 8–32 GB in a PCSmall: a few MB
  1. Power on: the CPU runs the firmware in ROM.
  2. POST: the power-on self-test checks the hardware.
  3. Bootstrap: the loader finds the OS on secondary storage and loads it into RAM.
  4. Run: the OS loads each program into RAM when opened.

Embedded systems (a washing machine) keep their fixed program in ROM.

Virtual memory and virtual storage

Virtual memory (1.2.1)

  • Used when RAM is full.
  • Part of secondary storage acts as extra RAM.
  • Pages not in use are moved out to the disk, and swapped back when needed.
  • ✓ More programs can run. ✗ Much slower than RAM.

Virtual storage (1.1.3)

  • Storage that appears local but is physically elsewhere: a network drive or the cloud.
  • ✓ Access anywhere, easy sharing, more space without new hardware, provider backs it up.
  • ✗ Needs a connection, slower, ongoing cost, data held by another company.

Read the question: “my H: drive is on the school server” is virtual storage; “the OS moves pages to disk when RAM is full” is virtual memory.

Watch out for:

  • “Temporary” and “permanent” with no detail – say volatile / non-volatile.
  • “Cheaper” with no comparison – say lower cost per GB.
  • Confusing virtual memory with virtual storage.
  • Giving a DVD when told “other than DVDs”.
  • No conclusion in a 9-mark discuss question.

Quick quiz – marked for you

1. A helmet camera for mountain biking. AO2

Flash (an SD card) is tough, light and small, with no moving parts to break.

2. A travel agent backs up 800 GB every night. AO2

Magnetic storage has the lowest cost per GB, and backup speed matters less overnight.

3. A new game sold in shops. AO2

Optical discs are very cheap to press in bulk and to post.

4. Where are a washing machine’s wash programs stored? AO2

They are fixed and must survive power off: non-volatile, read-only ROM.

5. “My H: drive is on the school server.” This is an example of… AO2

It looks like a local drive but is physically somewhere else: virtual storage.

6. What does volatile mean? AO1

RAM is volatile. ROM and secondary storage are non-volatile.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.1 exam tips for more help.

AO1[4 marks]

Explain the difference between RAM and ROM, including how these are used by the computer system. (October 2021)

Mark your answer

Tick each mark point your answer includes.

Model answer: RAM is volatile, so its contents are lost when the power is off. It stores the programs, data and parts of the operating system currently in use. ROM is non-volatile and stores the bootstrap program that starts the computer.

How to improve a weak answer:

  • Two parts each: a property, then what it is used for.
  • “RAM is temporary, ROM is permanent” scores at most 1 mark.
  • “Faster and bigger” is not on the mark scheme.
AO2[2 marks]

Amaya edits photographs on an old computer with 1 GB of RAM. Explain what is meant by ‘virtual memory’ and why it may be needed when Amaya is editing her photographs. (June 2023)

Mark your answer

Tick each mark point your answer includes.

Model answer: Virtual memory is an area of secondary storage used as extra RAM when RAM is full. Amaya may need it because her large photo files and the editing software could need more than her 1 GB of RAM.

How to improve a weak answer:

  • Define it, then apply it: link to the 1 GB RAM and large images.
  • Don’t confuse it with virtual storage.
AO3[9 marks]

Video elements are captured in different locations and then edited. Discuss the suitability of a flash storage device and a magnetic storage device for storing the video elements while they are collected and edited. (June 2023)

Mark your answer

Tick each mark point your answer includes.

Model answer: Flash storage has no moving parts, so it is safe to carry between filming locations and won’t be damaged by knocks. It also has fast read and write speeds, so large video files load quickly and play smoothly during editing. However, flash has a higher cost per GB, which matters because video files are very large. Magnetic storage has a much lower cost per GB, so it can store all the footage cheaply, but its moving parts could be damaged in transport and it is slower to load clips when editing. Overall, flash is best for collecting on location and for editing, and magnetic storage is best for archiving the footage afterwards.

How to improve a weak answer:

  • Use the grid: part (collecting, editing) → choose → because → but.
  • Every point must link to video, locations or editing.
  • Top band needs a conclusion justified by your points.

How to revise this

  • Comparison tables – magnetic vs flash vs optical; RAM vs ROM
