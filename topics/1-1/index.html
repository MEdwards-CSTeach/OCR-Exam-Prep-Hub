Question

Mixed quiz

Mixed quiz – marked for you

1. Which register holds the instruction currently being decoded? AO1

The Current Instruction Register. It is split into opcode and operand.

2. Which change would most help a program that splits easily into independent parts? AO2

Independent parts can run on different cores at the same time.

3. Instructions and data are fetched at the same time along separate buses. Which architecture? AO1

Harvard has separate memories and buses for instructions and data.

4. A smartwatch processor that must give long battery life. AO2

RISC’s simpler circuits use less power and produce less heat.

5. Tracking pallets in a warehouse without lining each one up. AO2

RFID needs no line of sight and reads many tags at once.

6. Storing the start-up instructions of a computer. AO2

ROM is non-volatile, so the bootstrap is still there when the power comes on.
