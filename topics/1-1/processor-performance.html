Processor performance

What makes one processor faster than another: clock speed, cores, cache and pipelining.

Three factors that affect performance

Clock speed

  • The system clock sends regular pulses that trigger each step of the FDE cycle.
  • Measured in hertz: 4 GHz = 4 billion cycles per second.
  • Faster clock = more instructions per second.
  • ✗ More heat and power.

Number of cores

  • Each core runs its own FDE cycle.
  • A quad-core can process four instructions at once.
  • ✗ Not four times faster: software may not use all cores, and some tasks must run in order.

Cache

  • Small, very fast, expensive memory on the CPU chip.
  • Holds recently used data and instructions, so fewer slow trips to RAM.
  • L1: smallest, fastest, split into instruction and data cache. L2: larger, slower.
  • More cache = more “cache hits”.

Pipelining

  • Overlaps the stages of the FDE cycle: while one instruction is executed, the next is decoded and another is fetched.
  • Components are not left idle, so more instructions are completed per second.
  • ✗ If a branch (jump) instruction changes the order, the pipeline is flushed and refilled.

Bus widths and memory size

  • The address bus width sets the maximum number of memory addresses: 2n for n lines.
  • Memory is divided into words; each word has its own address.
  • Memory size = number of addresses × word length in bytes.
  • The data bus width: if it matches the word length, a word moves in one operation.

Worked example: 8-line address bus, 16-bit words.
Addresses = 28 = 256
Word = 16 bits = 2 bytes
Memory = 256 × 2 = 512 bytes

Units: 1 KB = 1,000 bytes; 1 KiB = 1,024 bytes. KB (bytes) is not Kb (bits).

Watch out for:

  • Saying more cores makes a computer “twice as fast” – it depends on the software and the task.
  • Calling cache “fast storage” – it is memory, on the CPU chip.
  • Saying clock speed is how fast the CPU “thinks” – say cycles (FDE) per second.
  • Forgetting the drawback of pipelining: branches flush the pipeline.

Quick quiz – marked for you

1. How many different memory addresses can an 8-line address bus carry? AO2

Each line is a 0 or 1, so 8 lines give 28 = 256 different addresses.

2. A computer has an 8-line address bus and a 16-bit word. What is its maximum memory size in bytes? AO2

28 = 256 addresses × 2 bytes per word = 512 bytes.

3. A processor runs at 4 GHz. What does this mean? AO1

Giga = billion and hertz = cycles per second: 4 billion clock cycles each second.

4. Why is a quad-core processor not always four times faster than a single core? AO2

Parallel processing only helps when a task can be split into independent parts, and the software must be written to do it.

5. Level 1 cache is split into… AO1

Splitting L1 lets an instruction and data be fetched at the same time – a Harvard idea inside a modern CPU.

6. With a 3-stage pipeline (fetch, decode, execute), how many clock cycles do 3 instructions take? AO2

The first takes 3 cycles; each new instruction finishes one cycle later: 3 + 1 + 1 = 5 (without pipelining, 9).

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.1 exam tips for more help.

AO1[3 marks]

Describe three factors that affect the performance of a CPU.

Mark your answer

Tick each mark point your answer includes.

Model answer: A higher clock speed means more fetch-decode-execute cycles each second. More cores allow several instructions to be processed at the same time. A larger cache stores more frequently used data and instructions close to the CPU, so fewer have to be fetched from slower RAM.

How to improve a weak answer:

  • Don’t just name the factor – say how it improves performance.
  • Use precise terms: cycles per second, cache hits, RAM.
AO2[3 marks]

Explain how pipelining improves the performance of a processor.

Mark your answer

Tick each mark point your answer includes.

Model answer: With pipelining, while one instruction is being executed the next is being decoded and the one after that is being fetched. Because the stages overlap, no part of the processor sits idle, so more instructions are completed in the same time.

How to improve a weak answer:

  • Explain what overlaps, not just that it is “faster”.
  • For extra depth, mention that a branch instruction flushes the pipeline.
AO3[4 marks]

A student’s computer is slow when exporting large videos. Discuss whether a processor with a faster clock speed or one with more cores would help more.

Mark your answer

Tick each mark point your answer includes.

Model answer: Exporting video can be split into separate frames, so more cores could each work on different frames at the same time. A faster clock speeds up every instruction, which also helps parts of the task that must run in order. However, extra cores only help if the editing software is written to use them. As video export is easy to split and most editing software is multi-threaded, more cores would help most here.

How to improve a weak answer:

  • Weigh both options against the scenario: video export.
  • Finish with a clear judgement and a reason.
