Processor components and the FDE cycle

The parts of the CPU, what each register holds, and how an instruction is fetched, decoded and executed.

  • Address, data, control bus
  • Opcode, operand
  • Fetch-decode-execute

Inside the CPU

  • Control Unit (CU): coordinates all the other components, like a conductor. It decodes instructions and sends control signals on the control bus.
  • Arithmetic Logic Unit (ALU): does arithmetic (add, subtract, multiply, divide), logic (AND, OR, NOT, XOR) and shift operations.
  • Registers: tiny, super-fast memory locations inside the CPU.
  • Buses: sets of parallel wires (often 8, 16, 32 or 64 lines) that carry signals between components. Together they form the system bus.

Registers and buses

RegisterWhat it holds
PC – Program CounterThe address of the next instruction
MAR – Memory Address RegisterThe address to fetch from or store to
MDR – Memory Data RegisterData or an instruction moving to or from memory
CIR – Current Instruction RegisterThe instruction being decoded, split into opcode and operand
ACC – AccumulatorIntermediate results from the ALU
BusCarriesDirection
AddressMemory addressesOne way: CPU → memory
DataData and instructionsBoth ways
ControlControl signalsBoth ways

Control signals: memory read, memory write, bus request, bus grant, clock (keeps everything in step).

The fetch-decode-execute cycle

  1. Fetch: PC → MAR. The instruction at that address is copied to the MDR. At the same time the PC is incremented. MDR → CIR.
  2. Decode: the CU decodes the instruction in the CIR, splitting it into opcode (what to do) and operand (the data, or the address of the data).
  3. Execute: the instruction is carried out. The result is held in the ACC or stored in memory.
  4. Repeat for the next instruction. Interrupts are checked at the end of each cycle (1.2.1).

Watch out for:

  • Saying the PC holds the next instruction – it holds its address.
  • Forgetting the MDR step: the instruction goes MAR → memory → MDR → CIR.
  • Calling the address bus two-way – it is one way.
  • Mixing up the MAR (an address) and the MDR (data).

Quick quiz – marked for you

1. Which register holds the address of the next instruction to be fetched? AO1

The Program Counter holds the address of the next instruction. It is copied to the MAR at the start of the fetch.

2. Which bus only carries signals in one direction? AO1

The address bus carries addresses from the CPU to memory only. The data and control buses are two-way.

3. After the instruction arrives in the MDR, which register is it copied into? AO1

MDR → CIR. The instruction is then decoded from the Current Instruction Register.

4. Which control signal places data from the addressed location in RAM onto the data bus? AO1

Memory read copies the data at the address on the address bus onto the data bus. Memory write does the opposite.

5. During the fetch stage, what happens at the same time as the instruction is copied into the MDR? AO2

The PC is incremented while the instruction is fetched, so it is ready to point to the next instruction.

6. The operand of an instruction holds… AO2

The opcode says what to do. The operand is the data itself or the address where the data is.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.1 exam tips for more help.

AO1[2 marks]

Describe the purpose of the Control Unit.

Mark your answer

Tick each mark point your answer includes.

Model answer: The Control Unit coordinates the actions of all the other components of the processor. It decodes each instruction and sends control signals, such as memory read, along the control bus.

How to improve a weak answer:

  • Give two separate points for two marks: what it does overall, and how.
  • “It controls the computer” is too vague – say what it coordinates and how.
AO2[4 marks]

Describe the fetch stage of the fetch-decode-execute cycle. Refer to the registers used.

Mark your answer

Tick each mark point your answer includes.

Model answer: The address of the next instruction is copied from the PC into the MAR. The instruction stored at that address is copied along the data bus into the MDR, and at the same time the PC is incremented. The instruction is then copied from the MDR into the CIR.

How to improve a weak answer:

  • Name the registers in full or with the correct abbreviation.
  • Get the order right: PC → MAR → MDR → CIR.
  • Don’t drift into decode or execute – answer only the stage asked for.
AO2[3 marks]

Explain the role of each of the three buses when an instruction is fetched from memory.

Mark your answer

Tick each mark point your answer includes.

Model answer: The address bus carries the address of the instruction from the MAR to main memory. The control bus carries a memory read signal so that memory sends the contents of that address. The data bus then carries the instruction back into the MDR.

How to improve a weak answer:

  • One mark per bus: say what each one carries in this situation.
  • Link each bus to the register at the CPU end.

How to revise this

  • Flowcharts and process diagrams – draw the FDE cycle from memory
  • Mnemonics – “Please Make More Coffee”: PC → MAR → MDR → CIR
  • Flashcards – each register and bus, and what it holds

These are the best fit for this part of the topic, but you can use any revision technique that works for you.
