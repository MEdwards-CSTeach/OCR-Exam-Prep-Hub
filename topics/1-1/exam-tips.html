1.1 Components of a computer • Exam tips

1.1 exam tips

What examiners look for in questions on processors, devices and storage, with weak and good answers for each type of question.

Where it comes up

All of 1.1 is on Paper 1. Device questions are short and always set in a scenario. Storage and architecture often appear as 9-mark discuss questions, and CISC/RISC as a 12-mark question.

What the examiner looks for

Rewarded

  • Registers named correctly, in the right order (PC → MAR → MDR → CIR).
  • A named hardware device with a reason from the scenario (N-U-J).
  • A property, then its use: “ROM is non-volatile and stores the bootstrap.”
  • Comparisons in pairs: “CISC has…, whereas RISC has…”.
  • “Lower cost per GB”, “no moving parts”, “volatile”.
  • A justified conclusion in 9 and 12-mark answers.

Loses marks

  • Software instead of hardware: “a scanning app”.
  • Brand names: “an iPad”, “Intel”.
  • Two devices in one answer – only the first is marked.
  • “Temporary / permanent”, “faster”, “cheaper” with no detail.
  • Virtual memory when the question asks about virtual storage.
  • A graphical GPU use when a non-graphical one is asked for.

Weak and good answers

Question: Describe what is meant by the term ‘Von Neumann architecture’. [2]

Weak answer 0 marks

It is a type of computer that uses the fetch-execute cycle.

Good answer 2 marks

Data and instructions are stored in the same memory, and are transferred using one shared bus.

How to turn the weak answer into a good one:

  • Describe the feature that makes it von Neumann: one memory for both.
  • Add the second feature for the second mark: the single shared bus.
  • Every architecture uses fetch-execute, so that earns nothing.

Question: Explain the difference between RAM and ROM, including how these are used by the computer system. [4]

Weak answer 1 mark at most

RAM is temporary and ROM is permanent. RAM is faster and bigger.

Good answer 4 marks

RAM is volatile, so its contents are lost when the power is off. It stores the programs, data and parts of the OS in use. ROM is non-volatile and stores the bootstrap that starts the computer.

How to turn the weak answer into a good one:

  • Swap “temporary/permanent” for volatile/non-volatile, with what that means.
  • Add a use for each – the question asks how they are used.
  • Drop “faster and bigger”: it is not on the mark scheme.

Question: A home assistant listens for “Hey Bertie”, then answers the question. Name one input and one output device, with a reason for each. [4]

Weak answer 1 mark

Input: keyboard, to type questions. Output: printer, to output the answer.

Good answer 4 marks

Input: a microphone, so it can hear the spoken question. Output: a speaker, so it can play its spoken answer.

How to turn the weak answer into a good one:

  • Read the scenario: Bertie listens, so a keyboard doesn’t fit.
  • “To output the answer” is true of any device – say how this device is used.

Question: Describe one non-graphical use an insurance company may have for a GPU. [2]

Weak answer 0 marks

Running the website faster.

Good answer 2 marks

Modelling risk for millions of customers, because the same complex calculation is carried out on lots of data at the same time.

How to turn the weak answer into a good one:

  • Displaying a website is graphical, and “faster” alone gets nothing.
  • Name a numerical task and link it to the same calculation on lots of data.

Question: Why is a quad-core processor not always four times faster than a single-core processor? [2]

Weak answer 0 marks

Because the cores are slower.

Good answer 2 marks

Some parts of a task need the result of the step before, so they can’t run in parallel. The software may also not be written to use all four cores.

How to turn the weak answer into a good one:

  • Explain the limits of parallel processing: sequential steps and software.
  • Two separate reasons for two marks.
