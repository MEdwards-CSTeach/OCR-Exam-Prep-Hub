Karnaugh maps

Simplifying expressions with Karnaugh maps: Gray code, grouping rules and reading each group.

Key terms

  • Karnaugh map
  • Gray code
  • Group (1, 2, 4, 8)
  • Wrap-around
  • Overlapping groups
  • Revision notes
  • Links and slides

  • Exam questions

A truth table as a grid

  • Each cell is one row of the truth table. Fill in 1s (0s can be left blank).
  • Columns and rows use Gray code: 00, 01, 11, 10. Neighbouring cells differ by one bit only.
  • Never write 00, 01, 10, 11 – the map won’t work.
  • The map wraps round like a globe: left meets right, top meets bottom.

Grouping rules

Draw groups of 1s

  • Sizes 1, 2, 4 or 8 only
  • Rectangles only – no diagonals or L shapes
  • As big as possible, as few as possible
  • Groups may overlap and may wrap round the edges
  • Every 1 must be in a group

Read each group

  • Keep the variables that stay the same in every cell
  • Drop any variable that changes
  • 0 means NOT: write ¬A
  • Join the groups with ∨
  • Bigger group → fewer variables → simpler term

Worked examples

3 variables

Teal: ¬A ∧ C. Amber: A ∧ ¬B.
C \ AB00011110
00001
11101

(¬A ∧ ¬B ∧ C) ∨ (¬A ∧ B ∧ C) ∨ (A ∧ ¬B ∧ ¬C) ∨ (A ∧ ¬B ∧ C)
→ Q = (¬A ∧ C) ∨ (A ∧ ¬B)

4 variables (June 2025)

Teal (8): ¬C. Amber (4): A ∧ ¬B. Q = ¬C ∨ (A ∧ ¬B).
CD \ AB00011110
001111
011111
110001
100001

(¬C ∧ D) ∨ (¬C ∧ ¬D) ∨ (A ∧ C ∧ ¬B). A term without A or B fills a whole row.

Corners

The four corners are one group: ¬B ∧ ¬D.
CD \ AB00011110
001001
010000
110000
101001

Mark scheme pattern: 1 mark for the map, 1 for each correct group, 1 for the final expression. So show the map and ring the groups even if you can see the answer.

Watch out for:

  • Columns in the order 00, 01, 10, 11 – use Gray code 00, 01, 11, 10.
  • Groups of 3 or 6, or diagonal groups.
  • Missing a wrap-around group or the four corners.
  • Leaving a 1 out of every group.

Quick quiz – marked for you

1. What is the correct order for the AB columns of a Karnaugh map? AO1

Gray code: only one bit changes between neighbours.

2. Which group is NOT allowed? AO1

Groups must be 1, 2, 4 or 8 cells.

3. A group covers AB = 01 and 11, with C = 1. What is its term? AO2

A changes (0 and 1), so it drops out. B = 1 and C = 1 stay: B ∧ C.

4. Making groups bigger gives… AO1

A bigger group drops more variables, so the circuit is simpler – and the truth table doesn’t change.

5. Q is 1 when ABC is 010, 011, 110 or 111. Simplify Q to a single letter. AO2

These four cells form a group of 4 where only B stays the same (B = 1): Q = B.

6. On a 4-variable map, the four corner cells are 1 and nothing else. What is Q? AO3

The corners wrap round into one group of 4. B = 0 and D = 0 in all four: ¬B ∧ ¬D.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.3 exam tips for more help.

AO2[3 marks]

Use a Karnaugh map to simplify (A ∧ B ∧ ¬C) ∨ (A ∧ B ∧ C) ∨ (¬A ∧ B ∧ C).

Mark your answer

Tick each mark point your answer includes.

Model answer: 1s at 110, 111 and 011. Group 110 + 111 → A ∧ B. Group 011 + 111 → B ∧ C. Q = (A ∧ B) ∨ (B ∧ C), which can also be written B ∧ (A ∨ C).

How to improve a weak answer:

  • Overlapping groups are allowed – 111 is in both.
  • Show the map and the groups for the method marks.
AO2[4 marks]

Use a 4-variable Karnaugh map to simplify (¬A ∧ ¬B ∧ ¬D) ∨ (A ∧ ¬B ∧ ¬D) ∨ (B ∧ C ∧ D).

Mark your answer

Tick each mark point your answer includes.

Model answer: The first two terms fill the four corners (B = 0, D = 0), giving ¬B ∧ ¬D. B ∧ C ∧ D is a pair in the CD = 11 row (AB = 01 and 11). Q = (¬B ∧ ¬D) ∨ (B ∧ C ∧ D).

How to improve a weak answer:

  • Remember the corners are neighbours.
  • 1 mark per group – ring them clearly.
AO2[5 marks]

Group this map and write the simplified expression for Q. (June 2018)

Rows are CD, columns are AB.
CD \ AB00011110
001111
010011
110001
100001
Mark your answer

Tick each mark point your answer includes.

Model answer: Q = (¬C ∧ ¬D) ∨ (A ∧ ¬B) ∨ (A ∧ ¬C). Three groups of 4, which overlap.

How to improve a weak answer:

  • Look for the biggest groups first, then mop up any 1s left.
  • Overlapping is fine – it often gives bigger groups.

How to revise this

  • Worked examples – map, group, read – one step at a time
  • Trace tables – check your answer with a truth table
  • Spaced practice – a map or two every few days

These are the best fit for this part of the topic, but you can use any revision technique that works for you.
