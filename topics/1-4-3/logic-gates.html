  2. Count up in binary from 000 to 111.
  3. One column per gate, brackets first. Intermediate columns stop silly mistakes.

Defining problems with Boolean logic

Turn each condition into a letter, then join them with the right operators. “An alarm sounds (Q) if the door is opened (D) while the alarm is set (S), or the panic button is pressed (P)” → Q ≡ (D ∧ S) ∨ P. Brackets matter: D ∧ (S ∨ P) means something different.

Why simplify? (A ∧ B) ∨ (A ∧ ¬B) gives the same truth table as just A. Fewer gates means a cheaper, smaller chip that uses less power, makes less heat and is faster (each gate adds a tiny delay).

Watch out for:

  • Missing out rows: 3 inputs always need 8 rows, counted in binary.
  • Forgetting the bubble: a bubble on the output makes NAND or NOR.
  • Brackets in the wrong place when writing an expression from words.
  • Mixing up OR (1 if at least one) and XOR (1 if they differ).

Quick quiz – marked for you

1. Which gate outputs 1 only when its two inputs are different? AO1

XOR (exclusive OR) is 1 for 01 and 10, and 0 when the inputs match.

2. What does a NAND gate output when both inputs are 1? AO1

NAND is the opposite of AND. AND gives 1, so NAND gives 0.

3. How many rows does a truth table with 3 inputs need? AO1

2³ = 8 rows, from 000 to 111.

4. For Q = (A ∨ ¬B) ∧ C, what is Q when A = 0, B = 1, C = 1? AO2

¬B = 0, so A ∨ ¬B = 0 ∨ 0 = 0. Then 0 ∧ 1 = 0.

5. For Q = ¬(A ∨ B) ∧ C, what is Q when A = 0, B = 0, C = 1? AO2

A ∨ B = 0, so ¬(A ∨ B) = 1. Then 1 ∧ 1 = 1.

6. An alarm sounds (Q) if the door is opened (D) while the alarm is set (S), or the panic button (P) is pressed. Which expression? AO2

Door AND set must both be true, OR the panic button on its own. The brackets go round D ∧ S.

7. (A ∨ B) ∧ ¬(A ∧ B) behaves like which single gate? AO3

It is 1 when at least one input is 1 but not both – exactly XOR.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.3 exam tips for more help.

AO2[4 marks]

Complete the output column of the truth table for Q = (A ∧ B) ∨ ¬C. List Q for the rows ABC = 000, 001, 010, 011, 100, 101, 110, 111.

Mark your answer

Tick each mark point your answer includes.

Model answer: Q = 1, 0, 1, 0, 1, 0, 1, 1. Work out A ∧ B and ¬C in their own columns first, then OR them.

How to improve a weak answer:

  • Add intermediate columns for A ∧ B and ¬C – they make mistakes far less likely.
  • Check you have 8 rows counted in binary.
AO2[2 marks]

An alarm sounds (Q) if the door is opened (D) while the alarm is set (S), or the panic button is pressed (P). Write a Boolean expression for Q.

Mark your answer

Tick each mark point your answer includes.

Model answer: Q ≡ (D ∧ S) ∨ P

How to improve a weak answer:

  • Any accepted notation scores: AND, OR, . and + are all fine.
  • Brackets matter: D ∧ (S ∨ P) would mean something different.
AO3[3 marks]

A chip maker can build a circuit as (A ∧ B) ∨ (A ∧ ¬B) or as just A. Explain why the simpler version is better.

Mark your answer

Tick each mark point your answer includes.

Model answer: Both circuits give exactly the same output for every input, but the simplified one needs no gates at all. Fewer gates make the chip cheaper and smaller, use less power and produce less heat, and make it faster because every gate adds a small delay.

How to improve a weak answer:

  • Say first that the outputs are identical – that is why simplifying is allowed.
  • Give specific benefits, not just “better”.

How to revise this

  • Flashcards – gate symbol on the front, expression and truth table on the back
  • Trace tables – truth tables with an intermediate column per gate
  • Worked examples – expression → circuit → truth table

These are the best fit for this part of the topic, but you can use any revision technique that works for you.
