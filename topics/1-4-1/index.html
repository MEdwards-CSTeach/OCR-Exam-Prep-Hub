Mixed quiz

Mixed quiz – marked for you

1. Convert 1100 1010 to hex. AO2

1100 = 12 = C, 1010 = 10 = A. So CA.

2. Write −20 in 8-bit two’s complement. AO2

20 = 0001 0100 → flip: 1110 1011 → add 1: 1110 1100.

3. Convert 0.1101100 0100 (8-bit mantissa, 4-bit exponent) to denary. AO2

Exponent 4: 01101.100 = 8 + 4 + 1 + 0.5 = 13.5.

4. Which operator and mask flips every bit of a byte? AO2

XOR with 1 toggles each bit.

5. Which data type suits a phone number such as 07700 900123? AO3

It starts with 0 and you never do arithmetic on it, so a string.

6. How many bytes are in 2 KiB? AO2

2 × 1,024 = 2,048.
