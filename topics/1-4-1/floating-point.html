Floating point

Representing real numbers with a mantissa and exponent, normalising them, and adding and subtracting them.

How floating point works

Like standard form (75,000 = 0.75 × 105): a mantissa holds the digits and an exponent says where the point goes.

In these examples: an 8-bit mantissa and a 4-bit exponent, both in two’s complement. The mantissa’s first bit is the sign, with the binary point straight after it.

Floating point → denary

Positive

0.1101100 0100
Exponent 0100 = 4: move the point 4 right → 01101.100 = 13.5

Negative mantissa

1.0010100 0011
Exponent 3: move 3 right → 1001.0100. As two’s complement: −8 + 1 + 0.25 = −6.75

Negative exponent

0.1100000 1110
Exponent 1110 = −2: move the point 2 left → 0.0011 = 0.1875

Normalisation

  • Gives the most precision for the bits available, and one unique way to write each number.
  • A normalised positive number starts 0.1; a normalised negative number starts 1.0.
  • To normalise: shift the mantissa left until it starts 0.1 or 1.0, filling with 0s on the right. Subtract the number of places from the exponent.
BeforeShiftAfter
0.0011010 0100left 2, exponent 4 − 2 = 20.1101000 0010
1.1100011 0011left 2, exponent 3 − 2 = 11.0001100 0001

Denary → normalised floating point

17.25 → fixed point 10001.01 → move the point 5 left → 0.1000101 0101. For a negative number, find the two’s complement of the fixed point value first: −17.75 → 1.0111001 0101.

Adding and subtracting

  1. Convert both numbers to fixed point (this lines up the exponents).
  2. Add. To subtract, add the two’s complement of the second number.
  3. Convert the result back to normalised floating point.

Example: 0.1100000 0001 (1.5) + 0.1111100 0011 (7.75) = 1001.0100 (9.25) = 0.1001010 0100.

Mantissa vs exponent: more bits in the mantissa = more precision; more bits in the exponent = more range. With a fixed total, increasing one reduces the other.

Watch out for:

  • Moving the point the wrong way for a negative exponent.
  • Adjusting the exponent the wrong way when normalising: shift the mantissa left → subtract from the exponent.
  • Forgetting a negative mantissa is two’s complement.
  • Adding mantissas directly without first matching the exponents.

Quick quiz – marked for you

1. Convert 0.1011010 0011 (8-bit mantissa, 4-bit exponent) to denary. AO2

Exponent 3: 101.1010 = 4 + 1 + 0.5 + 0.125 = 5.625.

2. Convert 0.1100000 1110 to denary. AO2

Exponent 1110 = −2: move the point 2 left → 0.0011 = 0.125 + 0.0625 = 0.1875.

3. Convert 1.0010100 0011 to denary. AO2

Exponent 3 → 1001.0100. With −8 as the first place value: −8 + 1 + 0.25 = −6.75.

4. Normalise 0.0011010 0100. Give mantissa then exponent, e.g. 0.1000000 0001 AO2

Shift left 2 to get 0.1101000, so subtract 2 from the exponent: 4 − 2 = 2 = 0010.

5. Write 17.25 as a normalised floating point number (8-bit mantissa, 4-bit exponent). AO2

17.25 = 10001.01. Move the point 5 left: 0.1000101, exponent 5 = 0101.

6. Increasing the number of bits in the exponent (with the same total bits)… AO1

A bigger exponent can move the point further, so larger and smaller numbers can be stored – but fewer mantissa bits means less precision.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.1 exam tips for more help.

AO2[3 marks]

Convert −17.75 into a normalised floating point number with an 8-bit mantissa and a 4-bit exponent, both in two’s complement. Show your working.

Mark your answer

Tick each mark point your answer includes.

Model answer: 17.75 = 010001.11. Two’s complement: flip to 101110.00, add 1 → 101110.01. Move the point 5 places left to get a mantissa of 1.0111001 and an exponent of 5 = 0101.

How to improve a weak answer:

  • Find the two’s complement before normalising.
  • Check: a normalised negative mantissa starts 1.0.
AO2[3 marks]

Normalise the floating point number 1.1100011 0011 and explain why floating point numbers are normalised.

Mark your answer

Tick each mark point your answer includes.

Model answer: Shift the mantissa left 2 places so it starts 1.0: 1.0001100. Subtract 2 from the exponent: 3 − 2 = 1 = 0001. Normalising gives the most precision possible for the number of bits, and ensures each number has only one representation.

How to improve a weak answer:

  • A negative mantissa starts 1.0 when normalised.
  • Explain the purpose: precision and a unique form.
AO3[4 marks]

Add the floating point numbers A = 0.1100000 0001 and B = 0.1111100 0011. Give the answer as a normalised floating point number and show your working.

Mark your answer

Tick each mark point your answer includes.

Model answer: A = 0.1100000 × 2¹ = 1.1 (1.5). B = 0.1111100 × 2³ = 111.11 (7.75). A + B = 1001.01 (9.25). Moving the point 4 places left gives a mantissa of 0.1001010 and an exponent of 4 = 0100.

How to improve a weak answer:

  • Convert to fixed point first – you can’t add mantissas with different exponents.
  • Check by converting each number to denary: 1.5 + 7.75 = 9.25.
