Applied bit by bit to a whole byte:

     1010     1010     1010
AND  1100  OR 1100  XOR 1100
   = 1000   = 1110   = 0110

The second value is a mask.

Using masks

To…OperatorMask bit to changeMask bit to keep
Clear a bit (make it 0)AND01
Set a bit (make it 1)OR10
Toggle a bit (flip it)XOR10
Test a bitAND10 – result 0000 0000 means the bit was 0

Memory hook: AND is the only one where the “keep” bit is 1. Example: a settings byte 1010 0110; turn bit 6 (Alerts) off with AND 1111 1011 → 1010 0010. XOR twice with the same mask gives the original back – the idea behind simple encryption.

Shifts

ShiftWhat happensUsed for
LogicalBits move; a 0 fills the gap. The bit that falls off goes into the carry.Multiply / divide positive numbers by 2; testing the LSB
ArithmeticRight: the sign bit (MSB) is copied in, so the sign is kept. Left: the sign bit is kept.Multiply / divide two’s complement numbers
Circular (with carry)The carry goes into the empty end; the bit that falls off goes into the carry. No bits are lost.Rotating bits

Shift left 1 = × 2. Shift right 1 = ÷ 2, rounding down (the carry holds the remainder). Multiply with shifts and adds: 13 × 10 = 13 × 8 + 13 × 2 = shift left 3 (104) + shift left 1 (26) = 130.

Watch out for:

  • Giving only the operator or only the mask – a question usually wants both.
  • Using a logical shift right on a negative number – the 0 coming in makes it positive.
  • Getting the “keep” bit wrong for AND (it is 1).
  • Counting bits from the wrong end – check how the question numbers them.

Quick quiz – marked for you

1. What is 1010 AND 1100? AO2

AND gives 1 only where both bits are 1: 1000.

2. Which operator should be used to set particular bits to 1? AO1

OR with a mask bit of 1 sets that bit; a mask bit of 0 leaves the bit unchanged.

3. What is 1010 1101 XOR 1111 0000? AO2

XOR with 1 flips the bit; with 0 it keeps it. The left nibble flips: 0101 1101.

4. Logical shift 1011 0100 right one place. Give the 8 bits. AO2

Every bit moves right and a 0 comes in on the left: 0101 1010.

5. Arithmetic shift 1011 0100 right one place. Give the 8 bits. AO2

The sign bit (1) is copied in on the left to keep the number negative: 1101 1010.

6. A settings byte is 1010 0110. Give the AND mask that turns bit 6 (from the left) off and keeps the rest. AO2

AND with 0 clears a bit; 1 keeps it. A 0 only in position 6: 1111 1011.

7. Why should an arithmetic shift, not a logical shift, be used to halve a negative two’s complement number? AO3

A logical shift puts a 0 in the MSB, turning the negative number positive.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.1 exam tips for more help.

AO2[2 marks]

An 8-bit register holds the two’s complement value 1001 0110. State the contents after (a) a logical shift right of 2 places and (b) an arithmetic shift right of 2 places.

Mark your answer

Tick each mark point your answer includes.

Model answer: (a) 0010 0101 – two 0s come in on the left. (b) 1110 0101 – the sign bit 1 is copied in twice.

How to improve a weak answer:

  • Write all 8 bits.
  • Say (or think about) what fills the gap for each type of shift.
AO2[2 marks]

State the operator and mask that would set the two most significant bits of a byte to 1, leaving the other bits unchanged.

Mark your answer

Tick each mark point your answer includes.

Model answer: OR with the mask 1100 0000.

How to improve a weak answer:

  • Two marks: one for the operator, one for the mask.
  • Set = OR. A 1 where you want the change, 0 where you don’t.
AO3[2 marks]

Explain why an arithmetic shift, rather than a logical shift, should be used to divide the value 1001 0110 by 4.

Mark your answer

Tick each mark point your answer includes.

Model answer: The value is negative because its most significant bit is 1. A logical shift would bring 0s in on the left, making the result positive and wrong, whereas an arithmetic shift copies the sign bit in, so the result stays negative.

How to improve a weak answer:

  • Say the number is negative and why (MSB is 1).
  • Compare what each shift puts into the MSB.
AO2[3 marks]

Show how 13 × 10 can be calculated using only shifts and addition.

Mark your answer

Tick each mark point your answer includes.

Model answer: 10 = 8 + 2. 13 × 8 = 13 shifted left 3 places = 0110 1000 (104). 13 × 2 = 13 shifted left 1 place = 0001 1010 (26). Add them: 1000 0010 = 130.

How to improve a weak answer:

  • Split the multiplier into powers of 2.
  • Show each shifted value in binary, then the addition.

How to revise this

  • Worked examples – masks and shifts step by step
  • Mnemonics – “AND keeps with 1”: clear = AND 0, set = OR 1, toggle = XOR 1
