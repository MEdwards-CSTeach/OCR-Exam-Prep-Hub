Negative numbers

Sign and magnitude

  • The most significant bit is the sign: 0 = positive, 1 = negative. The other 7 bits are the size.
  • −3 = 1000 0011. Range in 8 bits: −127 to +127.
  • ✗ Arithmetic doesn’t work normally: 0000 0011 (3) + 1000 0011 (−3) = 1000 0110 = −6, not 0.
  • ✗ It also has two zeros: 0000 0000 and 1000 0000.

Two’s complement

Denary → two’s complement

  1. Write the positive number: 77 = 0100 1101
  2. Flip every bit: 1011 0010
  3. Add 1: 1011 0011 = −77

Check by adding the place values with −128 at the front.

Range

  • n bits: −2n−1 to 2n−1 − 1.
  • 8 bits: −128 (1000 0000) to 127 (0111 1111).
  • Same number of values as unsigned (256) – half are negative.
  • ✓ Normal addition works, so subtraction is done by adding a negative – no extra circuits.

Watch out for:

  • Giving sign and magnitude when two’s complement is asked for (and the other way round).
  • Forgetting to add 1 after flipping the bits.
  • Not using 8 bits: always write all of them, including leading 0s or 1s.
  • Saying the range is −127 to 127 for two’s complement – it is −128 to 127.

Quick quiz – marked for you

1. Write −3 as an 8-bit sign and magnitude number. AO2

Sign bit 1 for negative, then 3 in the other 7 bits: 1000 0011.

2. Write −77 as an 8-bit two’s complement number. AO2

77 = 0100 1101 → flip: 1011 0010 → add 1: 1011 0011.

3. Write −66 as an 8-bit two’s complement number. AO2

66 = 0100 0010 → flip: 1011 1101 → add 1: 1011 1110.

4. What denary value is the two’s complement number 1111 1101? AO2

−128 + 64 + 32 + 16 + 8 + 4 + 1 = −3.

5. What is the smallest number an 8-bit two’s complement number can hold? AO1

1000 0000 = −128. The range is −128 to 127.

6. Why is two’s complement used instead of sign and magnitude? AO2

With sign and magnitude, 3 + (−3) gives −6. Two’s complement arithmetic works with the same adder circuits.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.1 exam tips for more help.

AO1[2 marks]

Describe how sign and magnitude is used to represent a negative number in binary.

Mark your answer

Tick each mark point your answer includes.

Model answer: The most significant bit shows the sign, where 1 means negative and 0 positive. The rest of the bits store the size (magnitude) of the number as normal binary.

How to improve a weak answer:

  • Say which bit and what 1 or 0 means.
  • Say what the other bits do.
AO2[2 marks]

Convert −45 into an 8-bit two’s complement binary number. Show your working.

Mark your answer

Tick each mark point your answer includes.

Model answer: 45 = 0010 1101. Flip the bits: 1101 0010. Add 1: 1101 0011. Check: −128 + 64 + 16 + 2 + 1 = −45.

How to improve a weak answer:

  • Show each step – a slip in the last step can still earn the method mark.
  • Check your answer by converting it back.
AO3[3 marks]

Explain why two’s complement is normally used to store negative integers rather than sign and magnitude.

Mark your answer

Tick each mark point your answer includes.

Model answer: In sign and magnitude, normal binary addition gives the wrong answer – for example 3 + (−3) gives −6. In two’s complement, normal addition works for negative numbers, so subtraction can be done by adding the two’s complement of a number. This means the processor doesn’t need extra circuits for subtraction.

How to improve a weak answer:

  • Give an example of sign and magnitude going wrong.
  • Link the benefit to the processor: one adder does both jobs.

How to revise this

  • Worked examples – flip-and-add-1, then check by converting back
  • Trace tables – track each bit through flip and add 1
  • Teach it – explain why sign and magnitude arithmetic fails

These are the best fit for this part of the topic, but you can use any revision technique that works for you.
