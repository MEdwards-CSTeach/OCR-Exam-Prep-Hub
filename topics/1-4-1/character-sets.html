Character sets and binary prefixes

Binary prefixes

DecimalBytesBinaryBytes
kilobyte (kB)10³ = 1,000kibibyte (KiB)2¹⁰ = 1,024
megabyte (MB)10⁶mebibyte (MiB)2²⁰ = 1,048,576
gigabyte (GB)10⁹gibibyte (GiB)2³⁰
terabyte (TB)10¹²tebibyte (TiB)2⁴⁰

The “i” means a binary prefix. A 1 TB drive shows as 931 “GB” in Windows because 10¹² ÷ 2³⁰ = 931.3 – Windows divides by binary prefixes but still writes GB.

Character sets

  • A character set is an agreed table giving each character a unique binary code, so text means the same on every computer.
  • n bits give 2n characters.

ASCII

  • 7 bits: 128 characters – English letters, digits, punctuation.
  • Codes 0–31 are control codes (Enter = 13, Esc = 27). Space = 32.
  • '0' = 48, 'A' = 65, 'a' = 97. Cases are exactly 32 apart – one bit.
  • Extended ASCII: 8 bits, 256 characters (©, é, £…).

Unicode

  • Represents characters from every language, plus maths symbols and emoji.
  • Uses 16 or 32 bits per character (variable length).
  • The first 128 codes are the same as ASCII.
  • ✗ More bits per character, so files take more storage and longer to send.

Characters are not numbers

  • The character '5' is code 53 = 0011 0101. The integer 5 is 0000 0101.
  • So "9" + "3" gives "93" (joining strings), but 9 + 3 gives 12.
  • Strings sort by character code: "Zebra" < "apple" because 'Z' (90) < 'a' (97); and "10" < "9" because '1' (49) < '9' (57).
  • Masks change case: AND 1101 1111 → uppercase; OR 0010 0000 → lowercase; XOR 0010 0000 → swap.

Watch out for:

  • Writing 1 KiB = 1,000 bytes – it is 1,024.
  • Saying 7-bit ASCII has 256 characters – it has 128 (8-bit extended ASCII has 256).
  • Storing the character '9' as 1001 – it is 0011 1001 (57).
  • Saying Unicode replaced ASCII completely – the first 128 Unicode codes are ASCII.

Quick quiz – marked for you

1. 'A' is 65. What is the ASCII code for 'M'? AO2

M is the 13th letter: 65 + 12 = 77.

2. '5' has the ASCII code 53. Give the 8-bit binary for the character '5'. AO2

53 = 32 + 16 + 4 + 1 = 0011 0101. (The integer 5 would be 0000 0101.)

3. How many bytes are in 4 KiB? AO2

1 KiB = 1,024 bytes, so 4 × 1,024 = 4,096.

4. How many different characters can 7-bit ASCII represent? AO1

27 = 128.

5. Why is "Zebra" < "apple" True when comparing strings? AO3

Strings are compared by character code, and every uppercase letter (65–90) comes before every lowercase letter (97–122).

6. Which mask turns any ASCII letter into uppercase? AO2

Uppercase letters have the 32 bit set to 0. AND with 0 in that position clears it; 1s elsewhere keep the rest.

AO2[2 marks]

The character '5' has the ASCII code 53. Give the 8-bit binary for the character '5' and for the integer 5.

Mark your answer

Tick each mark point your answer includes.

Model answer: The character '5' is 0011 0101 (53). The integer 5 is 0000 0101.

How to improve a weak answer:

  • Don’t mix them up – a digit character is stored as its code, not its value.
AO1[3 marks]

Explain why Unicode was introduced, and give one disadvantage of Unicode compared with ASCII.

Mark your answer

Tick each mark point your answer includes.

Model answer: ASCII can only represent 128 characters (256 in extended ASCII), which is mostly the English alphabet. Unicode was introduced so that characters from every language, as well as symbols and emoji, each have one standard code. However, Unicode uses more bits per character, so text files take up more storage and take longer to send.

How to improve a weak answer:

  • Explain the limit of ASCII before the benefit of Unicode.
  • Make the disadvantage specific: more bits → more storage.
AO2[2 marks]

A new 1 TB hard drive is shown as about 931 GB by an operating system. Explain why.

Mark your answer

Tick each mark point your answer includes.

Model answer: The manufacturer measures 1 TB as 10¹² bytes. The operating system divides by binary units of 2³⁰ bytes (gibibytes) but still labels them GB, and 10¹² ÷ 2³⁰ ≈ 931.

How to improve a weak answer:

  • Show the calculation.
  • Name both kinds of prefix: decimal (GB) and binary (GiB).
