Data types, binary and hexadecimal

The primitive data types, and how to represent and convert whole numbers in binary, denary and hexadecimal.

Choose the data type from what the data is and what you will do with it. A phone number is a string: it can start with 0 and you never do arithmetic on it.

Binary: base 2

  • Computers use binary because circuits are either on (1) or off (0). Each binary digit is a bit; 8 bits make a byte.
  • Place values double from right to left: 128, 64, 32, 16, 8, 4, 2, 1.
  • Binary → denary: add up the place values with a 1. 1011 0111 = 128 + 32 + 16 + 4 + 2 + 1 = 183.
  • Denary → binary: work from the left. Can 128 fit? If yes, write 1 and subtract. Repeat. 159 = 1001 1111.
  • n bits give 2n values: 0 to 2n − 1. 8 bits: 0 to 255.

Hexadecimal: base 16

  • Digits 0–9, then A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
  • 16 = 24, so one hex digit = four bits (a nibble).
  • Binary → hex: split into nibbles and convert each.
  • Denary → hex: divide by 16; the answer is the first digit and the remainder the second. 43 ÷ 16 = 2 r 11 → 2B.
  • Hex → denary: place values 256, 16, 1. 3F5 = (256 × 3) + (16 × 15) + 5 = 1013.

Why hex? Easier for people to read and remember than long binary; quicker to type; fewer copying errors; converts easily to and from binary. Used for colour codes (#364DB2 = red 36, green 4D, blue B2), MAC addresses, memory addresses and machine code.

Watch out for:

  • Saying hex is used because computers understand it – computers only use binary. Hex is for people.
  • Dropping leading zeros when a set number of bits is asked for: 5 in 8 bits is 0000 0101.
  • Confusing B (11) and D (13) – write the hex table down at the start of the exam.
  • No working: conversions often have a method mark.

Quick quiz – marked for you

1. Convert the binary 1011 0111 to denary. AO2

128 + 32 + 16 + 4 + 2 + 1 = 183.

2. Convert 159 to 8-bit binary. AO2

159 − 128 = 31 → 31 = 16 + 8 + 4 + 2 + 1. So 1001 1111.

3. Convert 47 to hexadecimal. AO2

47 ÷ 16 = 2 remainder 15. 15 is F, so 2F.

4. Convert the hex A3 to denary. AO2

A = 10: (16 × 10) + 3 = 163.

5. Convert the binary 1101 1000 to hex. AO2

Split into nibbles: 1101 = 13 = D, 1000 = 8. So D8.

6. A program stores whether a door is locked. Which data type? AO2

Locked or not locked has only two values: True or False, so Boolean.

7. Why is hexadecimal used? AO1

Hex is a shorthand for binary for humans. The computer still stores binary.

Exam-style questions – mark them yourself

Write your answer, then open Mark your answer. Tick the mark points you hit, read the model answer and use the tips to improve. See the 1.4.1 exam tips for more help.

AO1[2 marks]

Give two reasons why hexadecimal is often used instead of binary.

Mark your answer

Tick each mark point your answer includes.

Model answer: Hexadecimal is easier for people to read and remember than long strings of binary, and there is less chance of making a mistake when copying it, because one hex digit replaces four bits.

How to improve a weak answer:

  • Don’t say computers “use” hex – it is for humans.
  • Give two different reasons, not the same one twice.
AO2[2 marks]

Convert the denary number 237 into (i) 8-bit binary and (ii) hexadecimal. Show your working.

Mark your answer

Tick each mark point your answer includes.

Model answer: 237 − 128 = 109, − 64 = 45, − 32 = 13, − 8 = 5, − 4 = 1, − 1 = 0, so 1110 1101. Split into nibbles: 1110 = 14 = E, 1101 = 13 = D, so ED.

How to improve a weak answer:

  • Use the binary answer to get the hex – split it into nibbles.
  • Check: E × 16 + D = 224 + 13 = 237.
AO2[4 marks]

A membership record stores a name, an age in years, a height in metres and whether the person has paid. State a suitable data type for each field.

Mark your answer

Tick each mark point your answer includes.

Model answer: Name – string; age – integer; height – real; paid – Boolean.

How to improve a weak answer:

  • Think about what the data is: whole number, decimal, true/false, or text.
  • “Number” is not a data type – say integer or real.
